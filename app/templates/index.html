🔐 DEVSECOPS PROJECT

Secure CI/CD Pipeline

A security-focused CI/CD pipeline that automatically analyzes source code, detects secrets, scans dependencies and Docker images before deploying applications to AWS.

🐙 GitHub

Version control and source management for the project.

🛡️ Semgrep

Static application security testing for detecting insecure coding patterns.

🔑 Gitleaks

Detects accidentally committed secrets, credentials and sensitive tokens.

🔍 Trivy

Scans Docker container images for known HIGH and CRITICAL vulnerabilities.

🐳 Docker

Packages the application into a portable and reproducible container.

☁️ AWS

Amazon ECR stores the container image and EC2 runs the deployed application.
