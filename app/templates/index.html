Secure CI/CD Pipeline

A production-style DevSecOps pipeline that automatically tests, scans, builds, secures and deploys a Flask application using GitHub Actions, Docker, Trivy, Amazon ECR and AWS EC2.

How I demonstrate this project

  1. Show the GitHub repository and project structure.
  2. Open GitHub Actions and explain the CI/CD workflow.
  3. Demonstrate automated tests.
  4. Explain Semgrep SAST security scanning.

  6. Explain Docker image creation.

  12. Show the pipeline automatically running again.
  13. Finally demonstrate the updated application running on AWS EC2.
